# Catalyst Data Store — manual console provisioning checklist

Generated by `scripts/generate_catalyst_console_checklist.py` from
`docs/deployment/catalyst-schema-manifest.json`, for live, by-hand entry
into the KSP-CIP Development project console (Cloud Scale -> Data
Store). One table, one column at a time -- Catalyst has no bulk-create
for either. Regenerate this file whenever the manifest changes; do not
hand-edit it.

## Read this first

- **Every new table already has 4 system columns**: `ROWID` (bigint,
  the real storage primary key), `CREATORID` (bigint), `CREATEDTIME`
  (datetime), `MODIFIEDTIME` (datetime). Do not recreate these -- only
  add the columns listed below per table.
- **Data Type dropdown** offers: Text, Var Char, Date, DateTime, Int,
  Double, Boolean, Bigint, Foreign Key, Encrypted Text.
- **`Text` has no Is Unique / Search Index option** -- only Var Char and
  the numeric types expose those toggles. That is why every column
  needing uniqueness below is typed `Var Char`, not `Text`, even though
  the source schema declares it `TEXT`.
- **Var Char max length is capped at 255** by Catalyst itself. Every
  `Var Char` row below uses 255.
- **`Search Index` is Catalyst full-text search integration, not a query
  index.** It is deliberately left off everywhere in this checklist --
  turning it on does not give you the SQL-style index the original
  schema declares.
- **Composite primary keys cannot be enforced at the Data Store level.**
  Catalyst's `Is Unique` constraint is single-column only. The tables
  below with more than one PK column (cip_conversation_turn, cip_kv, cip_unit_closure, ctl_row_hash, curated_CrimeHeadActSection, curated_Section)
  get `Is Mandatory` on every key column and **no** `Is Unique` --
  uniqueness across the combination is an application-level guarantee
  only, same as the app already assumes for Catalyst per
  `docs/deployment/catalyst-schema.md`.
- **None of the 46 indexes in the manifest are creatable in Catalyst
  Data Store.** There is no secondary/composite index feature for this
  service (indexing exists only in Catalyst NoSQL, a different
  service). This checklist does not attempt them -- see the note at the
  end of this file for what to record instead.
- One exception: `curated_CaseMaster.CrimeNo` is both a single-column
  unique index (`ux_case_crimeno`) in the manifest and expressible in
  Catalyst -- it is marked `Is Unique` below.
- Already created live: `audit_event.event_id`. Skip these if you reach them.

## Per-table steps

For each table: **Data Store -> + New Table -> type the table name -> Create**,
then for each column below: **+ New Column -> type Column Name -> pick Data
Type -> (Var Char only) set Max Length to 255 -> toggle Is Mandatory / Is
Unique as marked -> Create**.
